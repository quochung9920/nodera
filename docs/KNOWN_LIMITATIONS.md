# Known limitations

Version `0.1.0-alpha.2` is not a stable release.

- Built-in AI providers are intentionally absent; the initial workflow is provider-neutral Copy/Paste.
- Global Design intentionally exposes only a small native Global Styles surface in the first alpha.
- Dynamic Data initially proves one safe `core/post-meta` text source and Heading/Paragraph content bindings.
- Responsive overrides cover a bounded professional subset rather than every CSS property.
- Browser visual capture is measured only for editor DOM nodes that are reachable in the current editor/iframe context.
- Candidate preview is a Gutenberg BlockPreview, not pixel-level reference-image similarity.
- Manual screen-reader certification and broad commercial theme/plugin compatibility require separate real-environment evidence.
